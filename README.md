# NutriFreaks Website (Next.js)

Static Next.js frontend recreating [nutrifreaks.com](https://nutrifreaks.com), crawled from the live WordPress site. Built for SEO with the App Router, metadata, sitemap, and the same public URLs.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s included

- Homepage, About, Contact, Meal Plans / health goals, consultation form
- Goal pages (fat loss, diabetes, muscle gain, lifestyle, pregnancy, kids, elderly, recovery, vitamins, custom)
- English and Tamil blogs
- Policies, gallery, subscribe, body-fat calculator
- WhatsApp chat widget (Nila)

Login, payments, and WordPress membership are placeholders until a backend is connected.

## Production build

```bash
npm run build
npm start
```
